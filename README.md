> Portfolio personal que muestra mis proyectos de desarrollo web y animación. Diseñado como currículum interactivo para clientes y recruiters.

## 📋 Descripción

Este sitio web estático funciona como carta de presentación profesional. En él se destacan mis roles como **desarrollador backend**, **desarrollador frontend** y **animador**. Incluye secciones clave para mostrar experiencia, proyectos recientes, testimonios y un sistema de contratación, todo con modo oscuro y soporte bilingüe (español/inglés).

## 🚀 Tecnologías utilizadas

- **HTML5** – Estructura semántica
- **CSS3** – Estilos personalizados y modo oscuro
- **JavaScript** – Interactividad, cambio de idioma y modo oscuro
- **Bootstrap** – Layout responsive y componentes

## ✨ Características principales

- **Secciones:** Inicio, Sobre mí, Tecnologías, Proyectos recientes, Contratación, Testimonios de clientes.
- **Modo oscuro** – Alternancia manual con persistencia local.
- **Cambio de idioma** – Español / Inglés (sin dependencias externas).
- **Diseño responsive** – Adaptado a móviles, tablets y escritorio.
- **Totalmente estático** – No requiere backend ni variables de entorno.
